# TypeDuck Android

Android TypeDuck is being rebuilt on the Fcitx5 Android infrastructure, using
TypeDuck librime and the complete shared TypeDuck schema package.

## Build

See [FORK.md](FORK.md) for ownership conventions, remotes and the native dependency
pipeline. The Android application bundles Rime; no additional IME plugin APK is
required.

Install Android SDK 36, Build Tools 36.1.0, NDK 28.0.13004108 and CMake 3.31.6,
plus Extra CMake Modules and GNU gettext. The authoritative tool versions are in
`build-logic/convention/src/main/kotlin/Versions.kt`.

```sh
git submodule update --init --recursive
./gradlew :app:assembleDebug -PbuildABI=arm64-v8a
```

Omit `buildABI` to build the supported ABI set. The prebuilt dependency submodule
must contain outputs generated by the TypeDuck prebuilder.

## Product References

- TypeDuck iOS defines the candidate bar and dictionary panel behavior/design.
- TypeDuck Web defines the minimum feature scope.
- `lib/rime/src/main/schema` is the complete pinned TypeDuck schema package.

This preparation does not yet implement the TypeDuck candidate/dictionary UI or
complete product branding and release signing. Do not distribute it as a finished
TypeDuck release.
